Place the MySQL Connector/J driver JAR in this folder.

Expected file name (configured in nbproject/project.properties):
    mysql-connector-j-8.0.31.jar

Download it from:
    https://dev.mysql.com/downloads/connector/j/

Steps:
1. Download "Platform Independent (Architecture Independent), ZIP Archive".
2. Unzip it.
3. Copy "mysql-connector-j-8.0.31.jar" into this "lib" folder.

After that, clean & build the project in NetBeans (or Apache Ant) and run it.
